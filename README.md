## 🧠 Análise Teórica e Respostas do Laboratório

### A. O Papel do Engenheiro Júnior no Desenvolvimento Assistido por IA
O desenvolvimento assistido por IA muda o foco da escrita manual de sintaxe para a supervisão arquitetural. Para atuar nessa nova realidade, o engenheiro júnior precisa desenvolver três pilares essenciais:
1. **Pensamento Lógico:** Fundamental para conseguir modelar os problemas antes mesmo de passá-los para a máquina.
2. **Comunicação Técnica (*Prompt Engineering*):** A habilidade de orientar a IA de forma precisa, estruturada e contextualizada para obter os melhores resultados.
3. **Senso Crítico:** Capacidade indispensável para validar, testar e auditar as soluções geradas, garantindo que o código seja seguro e funcional.

### B. Engenharia Reversa: Do Plágio à Ferramenta de Verificação

* **B.1 O Conceito de Clone Direto:** Ocorre quando você copia todo o código-fonte de um site ou sistema de terceiros. Essa prática isolada gera apenas uma réplica sem valor agregado ou diferencial competitivo, aproximando-se do plágio se não houver autorização ou evolução.
* **B.2 Mitigação e Boas Práticas:** Para evitar o plágio no processo de engenharia reversa, é indispensável **usar ferramentas de verificação** e auditoria. O objetivo deve ser entender a arquitetura subjacente para reconstruir a lógica por conta própria, garantindo originalidade e conformidade ética no MVP final.
